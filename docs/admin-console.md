# 管理后台维护与验收

## 页面组织

后台位于 `admin/`，复用既有服务端接口与管理员权限。官网与后台的样式必须隔离，后台基础样式由 `.admin-shell` 限定。

菜单与面包屑的唯一配置为 `admin/src/navigation/adminNavigation.ts`。新增业务页需同时配置懒加载路由及该导航表，导航测试会核对每个正式路由都有唯一入口。尚未接入的认证占位页不进入导航。

- `/admin`：独立加载的待办、近 7 天任务状态、常用入口和最近审计。
- `/admin/analytics`：业务规模与趋势。
- 原业务 URL 保持不变；`/admin/security-audit` 跳转到 `/admin/security`。
- 未知后台路径显示 404；权限校验仍由现有前后端共同执行。

## 组件与数据规则

页面优先使用 `PageHeader`、`FilterBar`、`TableContainer`、`Section`、`StatusBadge`、`DetailPanel`、`DialogFrame`、`ConfirmDialog`。沿用原业务表单时也必须接入后台作用域样式和弹窗键盘行为。

工作台的 `useRemoteSection` 区分未取得数据、成功空结果和刷新失败。失败保留最后成功数据及时间，不能用 0 代替未知。服务端未给出全量计数时只显示最近记录，不合成总待办数量。

`useQueryState` 校验已有枚举，URL 记录搜索和筛选。用户、社区列表的本地搜索明确限于已加载记录。详情关闭保留当前列表；健康档案仅在管理员主动进入健康分区后读取。修改、审核、反馈等操作保留既有权限、版本校验、幂等键与审计要求。

## 2026-09-20 本地验收

使用独立 SQLite 数据库与本地 Express 服务；演示账号和测试反馈只存在于隔离环境。没有为本次验收修改生产业务数据。

- 所有 21 个正式导航入口分别检查桌面、1024px、390px 布局；页面主体无横向溢出，宽表格在自身容器滚动。
- 手机导航抽屉、用户详情分区、食谱只读详情、Escape 关闭及焦点返回通过。
- 内部备注保留公开状态；公开回复双击仅产生一条消息；相同请求键重放没有重复消息；版本冲突保留草稿并提示刷新。
- 取消停用账号未发出写请求；食谱发布质量校验仍有效，完整测试食谱可审核并退出待审队列。
- 独立代理注入食谱接口 503：首次失败不显示空待办；刷新失败保留旧数据；其他模块可用；故障移除后重试恢复。
- 运行 `pnpm lint:admin`、`pnpm test:admin`、`pnpm build:admin`。

## 发布与回滚

发布 admin 静态资源，不重新启动 API 或迁移数据库。先备份服务器实际挂载目录，校验候选文件哈希，上传资源后最后原子替换 `index.html`。保留旧哈希资源，记录源码提交、备份位置和部署回执。

发布检查包括正式域名的首页、管理路由入口、新 JS/CSS、Landing 资源、网页版入口哈希和 API 健康。失败时恢复旧入口文件；恢复脚本与完整旧资源备份放在对应服务器备份目录。
